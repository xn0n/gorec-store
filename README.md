# Горец — прототип магазина

**Витрина спортивного бренда: от главной страницы до оформления заказа.**

Frontend-прототип интернет-магазина с каталогом, карточками товаров и страницами покупательского пути. Это заготовка для развития e-commerce интерфейса: товары поступают из локальных данных, а оформление заказа пока демонстрирует будущую форму.

`React` · `TypeScript` · `Vite` · `React Router` · `Tailwind CSS`

## Что есть в проекте

- Главная страница с разделами бренда и подборкой товаров.
- Каталог и маршруты карточек товара.
- Страницы корзины и оформления заказа.
- Общие layout, навигация и UI-компоненты.
- Информационные маршруты доставки, оплаты, контактов и FAQ.
- Локальные данные товаров и frontend-сервисы доступа к ним.
- Папки для будущего backend и проектной документации.

## Запуск интерфейса

Команды выполняются из `frontend/`:

```powershell
npm install
npm run dev
```

```powershell
npm run build
npm run preview
```

В текущем manifest используются зависимости с версией `latest`, поэтому установка на разных датах может давать разные версии. Для воспроизводимого дальнейшего развития нужно зафиксировать версии и lockfile.

## Структура

```text
frontend/src/app/         точка входа и маршруты
frontend/src/pages/       страницы магазина
frontend/src/components/ layout, UI и товарные компоненты
frontend/src/data/        локальный каталог и текстовые данные
frontend/src/services/    frontend-сервисы
backend/                 заготовка будущего API
docs/                    заготовка документации
```

## Текущее состояние

Реальный API не реализован: backend-файлы и его manifest являются пустыми заготовками. Кнопка оформления заказа не отправляет данные, платежи, склад, доставка и сохранение заказов не подключены. Информационные и юридические страницы содержат placeholders.

Прототип не заявляет работающий магазин или подтверждённые характеристики продукции. Перед реальным запуском требуются собственные права на изображения и контент, проверенные описания товаров, обработка заказов, платежи, правовые тексты и проверка приложения. Автоматизированная тестовая команда в текущем manifest не определена.
